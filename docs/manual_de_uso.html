Reconciliación de Pagos

Manual de uso
Cruce automático de autorizaciones, contabilizaciones
y movimientos bancarios

Emanuel Villada Muñetón

¿Qué hace esta aplicación?

Compara tres archivos que hablan de las mismas transacciones —lo que se autorizó, lo que se contabilizó y lo que llegó al banco— y encuentra dónde dejan de coincidir. Al terminar entrega un Excel con una fila por transacción, señalando qué cuadra, qué no y por qué, además de las operaciones con indicios de fraude.

Todo el proceso tarda alrededor de un segundo y no requiere saber programar ni abrir una terminal.

Antes de empezar (solo la primera vez)

La aplicación necesita Python instalado y sus dos librerías. Si alguien ya dejó el equipo preparado, salta este paso.

pip install -r requirements.txt

Los tres archivos de datos deben estar en la carpeta datos/, con estos nombres exactos:

ArchivoContiene
autorizaciones.csvLas transacciones autorizadas
reconciliacion_pagos.dbLos registros contabilizados
movimientos_bancarios.jsonLo que reportó el banco
Para actualizar los datos, reemplaza estos tres archivos por los nuevos, respetando los nombres. La aplicación siempre lee de esa carpeta: no hay que buscarlos ni seleccionarlos.

Cómo abrirla

Doble clic en ejecutar_gui.bat. Eso es todo.

Si faltara algo por instalar, en lugar de no hacer nada aparecerá una ventana negra explicando qué falta. Si prefieres la terminal, también funciona python ejecutar_gui.py.

La ventana

Así se ve al abrir: todavía no se ha ejecutado nada.
1
Fuentes de datos. Los tres archivos con un punto al lado. Verde es que está donde debe; rojo es que falta. Si alguno está en rojo, el botón de ejecutar se deshabilita y abajo aparece qué falta.
2
Ejecutar reconciliación. El botón que arranca todo. A su lado, Cancelar (solo se activa mientras el proceso corre) y la barra de avance con el paso actual escrito.
3
Los cuatro indicadores. Aparecen con un guion hasta que ejecutes. Son el resumen de salud del resultado.
4
Detalle del proceso. El registro de todo lo que hizo, línea por línea, y los botones para abrir el Excel, su carpeta o guardar el registro.
5
Arriba a la derecha: tema Claro u Oscuro, y el botón Salir.

Ejecutar la reconciliación

1
Comprueba que los tres puntos estén en verde.
2
Pulsa Ejecutar reconciliación.
3
Espera. La barra avanza y el texto va diciendo en qué paso va («Escribiendo el reporte... (320/505)»). La ventana sigue respondiendo: si necesitas parar, pulsa Cancelar.
Durante el proceso: el avance se ve en tiempo real.
4
Al terminar aparecen los indicadores y, abajo, la ruta donde quedó el archivo.

Leer el resultado

Abrir el Excel

  • Abrir reporte — abre el archivo directamente.
  • Abrir carpeta — abre la carpeta, útil para adjuntarlo a un correo.
  • Guardar bitácora — guarda el detalle del proceso en un .txt, por si hay que dejar constancia de qué se hizo.

El archivo siempre queda en salida\reporte_reconciliacion.xlsx y se reemplaza en cada ejecución. Si necesitas conservar uno, cópialo o renómbralo antes de volver a ejecutar.

El Excel: cómo leerlo

Una sola hoja llamada Reconciliacion, con una fila por transacción y los valores de las tres fuentes lado a lado. La fila viene coloreada:

Naranja — hay indicios de fraude. Es lo primero que hay que mirar, incluso si lo demás cuadra.
Rojo — hay un problema: el monto no coincide, el estado no es correcto o la transacción falta en alguna fuente.
Verde — todo cuadra. No requiere acción.

Las columnas que más se usan

ColumnaPara qué sirve
ClasificacionEl diagnóstico en una palabra
ObservacionesLa explicación en lenguaje corriente. Es la columna que responde «¿por qué?»
Diferencia_MontoCuánto dinero de diferencia hay
Nivel_RiesgoCrítico, alto o medio, para priorizar
Centro_CostoA quién corresponde la transacción

La fila de encabezados está congelada y tiene autofiltro: se puede filtrar, por ejemplo, por Nivel_Riesgo = CRÍTICO para ver solo lo urgente. Los montos son números y las fechas son fechas de verdad, así que se pueden sumar y ordenar sin convertir nada.

Sugerencia de uso diario: filtra primero por Es_Fraude = SI y atiende eso; después por Clasificacion distinto de RECONCILIADO para revisar las diferencias. Lo verde no necesita que nadie lo mire.

Si algo sale mal

La aplicación no se cierra ni muestra errores técnicos: explica el problema en la parte de abajo de la ventana, en rojo.

Lo que vesQué pasóQué hacer
Un punto rojo y «No se encontraron: …»Falta un archivo de datosPonlo en la carpeta datos con el nombre exacto
«No se pudo guardar el reporte porque el archivo está abierto»El Excel anterior está abiertoCiérralo en Excel y vuelve a ejecutar
«El archivo … no es un JSON válido»El archivo del banco llegó dañadoPídelo de nuevo
«Ocurrió un error inesperado»Algo no previstoPulsa Guardar bitácora y envía ese archivo a soporte
Doble clic y no pasa nadaFalta Python o una libreríaAparecerá una ventana con la instrucción; ejecútala
Si cancelas el proceso a mitad, no se genera ningún reporte y el archivo anterior queda intacto. Cancelar es seguro.

Ejecutar sin interfaz

Para quien prefiera la terminal, o para dejarlo programado en una tarea automática:

python main.py

Hace exactamente lo mismo y muestra el avance y el resumen por consola. Devuelve código 0 si todo salió bien y 1 si falló, que es lo que necesita un programador de tareas para saber si debe alertar.

Preguntas frecuentes

¿Puedo dejar la ventana abierta y ejecutar varias veces?

Sí. Cada ejecución reemplaza el reporte anterior y limpia el detalle del proceso.

¿Se modifican los archivos de datos?

No. Los tres se abren solo para leer; la base de datos incluso se abre en modo de solo lectura. La aplicación únicamente escribe en la carpeta salida.

¿Por qué el total analizado es mayor que el número de filas del CSV?

Porque se analizan todas las transacciones que aparezcan en al menos una de las tres fuentes. Las que solo reporta el banco también cuentan —y son justamente las más importantes de revisar.

¿Qué pasa si una transacción tiene varios problemas a la vez?

Aparecen todas las etiquetas separadas por punto y coma, y la columna Observaciones explica cada una.
